# 临水轩 · 古风前端技术设计文档 v1.0

> 「临水轩」是衔枝Twig的第二套前端，与「记忆书」（`visualizer/`）并列、互不干扰，读同一个引擎 HTTP API。
> 审美纲领：**从「看画」到「入画」**——不是一张网页海报，而是一间临水的古风轩室。用户不是在浏览页面，而是走进一间屋子。

---

## 一、总体结构

```
临水轩（厅堂）
├── 五扇折叠屏风 ── 系统级子模块的物理入口（绢帛透光立地折屏，微风中轻晃）
│   ├── 屏一·桃花 ──「春水」：碎片层 / 记忆流。水幕荡开切入水面子页（本项目首个子页）
│   ├── 屏二·木铎 ──「采诗」：/v1/reflect + 故事线。铎响=反思完成、新线索成形（二期）
│   ├── 屏三·纸扇 ──「书阁」：日记 journal / 理解文档 claims，线装典籍翻页（二期）
│   ├── 屏四·琼瑶 ──「琼瑶」：心迹 / 便签 / 印章玉牒。投我以木桃，报之以琼瑶（二期）
│   └── 屏五·窗棂 ──「庭树」：引擎状态 / 自检 / 记忆生长树，虬枝随线索生长（二期）
└── 竹简对话台（左下角）── 「采诗官的书案」：真正的实时对话控制台，接 /v1/chat（全程可用）
```

- **信物即状态**：五扇信物不是静画，而是引擎数据的活体呈现——本周碎片多则桃花瓣密、新 ingest 则一瓣飘落、reflect 运行中则木铎轻颤、印章随章节收集、树随线索开枝。（二期逐扇接线）
- **风与时辰**：全屋共享一个 ambience——噪声驱动的「风值」+ 按真实时刻变化的晨/昼/暮/夜四套光色。花瓣、铎晃、丝绦、水波吃同一阵风；鼠标划过也生成微风。五组各自好看的动画只是五张图，共享同一阵风才是一间轩室。

## 二、视觉系统

三色锚点（宋瓷系，用于弥合日系水彩参考与中式工笔之间的气质差）：

| 令牌 | 色 | 用途 |
|---|---|---|
| 汝窑青 `--celadon` | #9fbfb7 系 | 水色、底色、环境 |
| 绢白 `--silk` | #f3ecdd 系 | 屏面、纸面、正文底 |
| 朱砂 `--cinnabar` | #a8402f 系 | 丝绦、印章、点睛、警示 |

辅色：黛青（正文墨色）、胭脂粉（桃花）、赭木（框、案、简）、泥金（高光点缀）。完整令牌见 `xuan/src/styles/tokens.css`，**所有颜色只允许引用令牌，不允许散落硬编码**。

字体：霞鹜文楷（OFL 开源，jsdelivr webfont，按 unicode-range 分片），本地回退 Kaiti/楷体栈。诗性引文可用竖排（`writing-mode: vertical-rl`），对话正文一律横排。

## 三、交互与动效

- **入画序章**：加载期水墨晕开（水蒙渐散），期间正好拉引擎状态——加载时间即仪式。
- **屏风转场**：点击屏面 → 屏风放大淡出 + 水幕涟漪扩散 → 子页入场。子页左上「回轩」退出。
- **竹简对话台**：静置左下角（系朱红丝绦、隐隐微光）；轻点丝绦解开、简册向右上横铺展开；引擎回复逐字晕染显现（引擎 `/v1/chat` 非流式，渐进显示由前端完成）。
- **可达性红线**：`prefers-reduced-motion` 时整屋退成静画（风停、波静、花瓣止）；音效默认开、右下「静」字开关；离屏 rAF 一律暂停。

## 四、春水子页 · 水引擎技术方案

- **版权声明**：技法参考 `D:\BaiduNetdiskDownload\flower-water-ripples`（© konmari），但**代码为自行重写**，不嵌入第三方文件。
- **路线**：CPU 粗网格（NX=160，NY 按纵横比自适应）双缓冲波动方程 → 打包 LUMINANCE 纹理 → WebGL1 shader 做折射、漫射、波峰亮斑、慢移天光带、游移光池 → 2D canvas 叠程序化桃瓣与星芒。指针划过=细涟，点击=投石+星芒迸溅。
- **花位标定**：底图上每朵花一个漩涡摆动区（photo UV + 半径），换图必重新标定。当前 `art/chunshui-bg-v1.png`（1536×1024）标定值写在 `xuan/src/water/flowers.ts`：

| 花 | cx | cy | r | 备注 |
|---|---|---|---|---|
| 左上 | 0.185 | 0.220 | 0.120 | |
| 右上 | 0.845 | 0.200 | 0.115 | |
| 正中 | 0.500 | 0.490 | 0.115 | 最大一朵 |
| 左下 | 0.175 | 0.720 | 0.120 | |
| 右下 | 0.815 | 0.765 | 0.130 | |

- **已知事项**：现图为 3:2，桌面 16:9 下 cover-crop 裁去上下约 15%，右上/右下两朵贴近裁切缘但仍在幅内；后续出图优先 16:9。
- 底图、花瓣调色板、光色均为宋式（汝窑青×胭脂×泥金），程序花瓣为桃瓣（尖端收拢），与后续「花瓣 sprite」资产可互换。

## 五、竹简对话台 · 技术方案

- `POST /v1/chat {userId, text}` → `{reply, contextInjected, ingest, crisisDetected}`。userId 首次生成存 `localStorage`。
- 回复以逐字墨迹晕染显示（约 28ms/字）；请求失败显示「引擎未醒」朱砂提示（引导先起 `npm run server:http`）。
- 会话历史暂存内存（引擎侧有进程内历史）；落盘与「召回透明化」（展示 contextInjected 摘要）排后续。
- 长文本上限 4000 字符，与引擎一致。

## 六、资产规范

**位图为体、SVG 为筋、程序为气**：装饰画面全 AI 位图；承载正文的表面 AI 只出空版（文字必须 HTML 可选中可流式）；路径动画（丝绦、线索标记）用 SVG；水波/焦散/墨迹用程序。完整清单见对话记录（第一批：春水背景✅、眺园图、桃花画心、花瓣 sprite、竹/木纹 tile；第二批：木铎、典籍空版、玉璧、印章×8）。

- 母版放仓库 `art/`（public 挂载点，dev 直接按根路径引用），命名 `模块-内容-版本`；压缩成 WebP 由工程侧负责。
- 五扇画心必须同批同风格生成，统一风格基底：「宋代工笔绢本设色、米白绢底、淡彩渲染、留白气韵、无文字无印章无框」。

## 七、工程与目录

```
xuan/                    # 临水轩，独立 Vite 应用，端口 7101（记忆书 7100 不受影响）
├── vite.config.ts       # root=xuan，/v1 代理到引擎 7300，fs.allow 指向仓库根（读 art/）
├── index.html
├── tsconfig.json
├── public/
└── src/
    ├── main.tsx / App.tsx        # 入口与厅堂⇄子页路由（useState，不引路由库）
    ├── styles/tokens.css         # 设计令牌
    ├── ambience.ts               # 时辰光色 + 风值
    ├── water/WaterEngine.ts      # 春水水引擎（自研重写）
    ├── water/flowers.ts          # 底图花位标定
    ├── pages/Hall.tsx            # 厅堂：五扇屏风
    ├── pages/SpringWater.tsx     # 春水子页
```

脚本：`npm run dev:xuan` / `npm run build:xuan`。美术资产 `art/` 位于仓库根，作为 xuan 的静态目录直接引用。
